Program a robot.
Send it into the dungeon.

Advolition is a game for programmers. You write a robot's brain in JavaScript, then up to four robots explore a random dungeon at once: scanning, collecting loot, fighting, and racing to bring their wealth home before time runs out.

Every robot can be saved as a trading card that carries its complete code on its back, in a strip of shaded blocks. Share the card, and anyone can load it into their shop.

Enter the Shop How to play

1 Load your robots

In the shop, load up to four robots from card images or JavaScript files, or start a new robot from a template.

2 Review the code

Read every robot's code before it fights. Edit it if you like, then save it as a new card to share.

3 Battle in the arena

Start the battle and watch the robots explore, fight and bank their loot. The highest score when time runs out wins.

Sample robots

These cards are working robots, each with a different style of play, for you to battle against, learn from, or use as a starting point. Each card has two sides: the front shows the robot, and the back holds its complete code (hover over a card to turn it over). Download a card and load the image in the shop to see and edit its code, or view the script. When you share a card, share the image file itself: sites that shrink or heavily re-compress images can damage the code strip.
